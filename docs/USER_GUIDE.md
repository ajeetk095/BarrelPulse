# User guide
* **Home** — latest-month regime, headline result, 3D regime space.
* **Live Market** — daily WTI / VIX / USD from FRED→EIA→Yahoo (first that answers), month-to-date, 20-day vol; model read-out for the latest complete month and next-month probabilities. *Refresh live data* clears caches.
* **Simulation Lab** — every parameter and the time range; 3D regime space; export CSV.
* **Scenario Explorer** — fix VIX / USD / industry / energy-CPI states; 3D surface of regime probability.
* **Data & Splits · Validation · Forecasting · Improvements** — report-configuration pages with the same panels; sweeps in 3D.
* **Risk & Robustness** — Monte-Carlo regime paths, illustrative rule with costs, robustness tables.
* **Contributions · Discussion · Methodology · About · Developer**.
Each parameter panel has **↺ Reset all**, restoring every setting and the time range to that page's default. Data source: *Bundled snapshot* or *Live*; live falls back automatically and the banner shows the origin. Nothing here is investment advice.
